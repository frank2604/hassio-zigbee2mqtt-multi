# Zigbee2MQTT 4 Ankleide

Instanz des offiziellen Zigbee2MQTT-Add-ons.
Datenverzeichnis: `/config/zigbee2mqtt_4_ankleide`

Diese Instanz unterscheidet sich vom offiziellen Add-on ausschliesslich in
`name`, `slug`, `data_path` und der abgeschalteten Socat-Port-Freigabe.
Das Container-Image ist unveraendert das offizielle
`ghcr.io/zigbee2mqtt/zigbee2mqtt-{arch}`.
